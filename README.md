# Repair Request System API (ใบงานที่ 2)

ระบบจัดการคำขอแจ้งซ่อมคอมพิวเตอร์และอุปกรณ์ด้วย Node.js และ Express ตามมาตรฐาน RESTful API

## วิธีการติดตั้งและรันโปรเจกต์
1. ติดตั้ง Dependencies:
   ```bash
   npm install
   ```
   2. รันเซิร์ฟเวอร์: `node src/app.js`
3. ทดสอบเรียกใช้งาน API ผ่านเบราว์เซอร์หรือ Postman ที่ URL: `http://localhost:3000/api/v1/repair-requests`

## ตารางเทียบ Use Case และ API Endpoints

| Use Case | HTTP Method | Endpoint | คำอธิบาย | Status Codes |
| :--- | :--- | :--- | :--- | :--- |
| ดูรายการแจ้งซ่อมทั้งหมด | `GET` | `/api/v1/repair-requests` | ดึงข้อมูลคำขอแจ้งซ่อมทั้งหมด | `200` |
| ดูรายละเอียดคำขอแจ้งซ่อม | `GET` | `/api/v1/repair-requests/:id` | ดึงข้อมูลคำขอแจ้งซ่อมตามรหัส ID | `200`, `404` |
| สร้างคำขอแจ้งซ่อมใหม่ | `POST` | `/api/v1/repair-requests` | เพิ่มรายการแจ้งซ่อมใหม่เข้าสู่ระบบ | `201`, `400` |
| อัปเดตสถานะการซ่อม | `PUT` | `/api/v1/repair-requests/:id` | แก้ไขสถานะ มอบหมายช่าง และบันทึกผลซ่อม | `200`, `400`, `404` |
| ลบคำขอแจ้งซ่อม | `DELETE` | `/api/v1/repair-requests/:id` | ลบรายการแจ้งซ่อมออกจากระบบ | `204`, `404` |

## สรุปและวิจารณ์ผลการปฏิบัติงาน
- **ความสอดคล้องกับแผนภาพ UML:** Endpoint ทั้ง 5 เส้นที่พัฒนาขึ้นสอดคล้องกับ Use Case และ Class Diagram ของระบบแจ้งซ่อมจากสัปดาห์ที่ 1 โดยแยกการทำงานเป็นส่วน Routes และ Controllers อย่างชัดเจน
- **ปัญหาที่พบและแนวทางแก้ไข:** ระหว่างการทดสอบส่งข้อมูลแบบ `POST` พบปัญหา `req.body` เป็น `undefined` เนื่องจากยังไม่ได้ตั้งค่า Middleware `express.json()` รวมถึงการเลือกประเภท Body ใน Postman เป็น `raw -> JSON` เมื่อแก้ไขแล้วระบบสามารถรับส่งข้อมูลและตอบกลับ Status Code ได้ถูกต้องครบถ้วน
